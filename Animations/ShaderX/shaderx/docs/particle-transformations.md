# Particle transformations

Formation examples use persistent particle identities and spring dynamics. Crane assembly and Butterfly assembly interpolate from deterministic full-canvas scatter targets to a faceted bird and a filled wing surface. Leaf to bloom interpolates a filled leaf into a five-petal flower. The Assembly / Leaf to bloom Kin slider changes targets, not the particle buffer; velocity carries each point through the transition. Reversing the slider dissolves or reforms the same particles. Paused parameter edits update the shape immediately.

These are code-defined forms, not image imports or automatic image reconstruction. Drag disturbs the assembled surface and release lets it recover. Butterfly wing movement is internal; these themes do not automatically rotate around the canvas.

Woven field replaces Orbital dust in the visible catalog while retaining its existing recipe ID and density/pull parameters. Pull is now labeled Weave tension. Copper storm uses lateral drift, and full-screen field touch forces disperse particles without orbital swirl. Vortex descent remains separate.

Validation checks particle buffer identity, bounded per-frame morph displacement, finite settled state, endpoint renders, and the existing application flows.
